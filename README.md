# Olist E-Commerce Sales & Customer Analytics

## Project Overview
This portfolio project analyses the Olist Brazilian E-Commerce dataset to understand sales performance, customer behaviour, delivery performance, product categories, payments and customer satisfaction.

The project is designed to demonstrate practical skills in:
- Python
- Pandas
- SQL
- Exploratory Data Analysis (EDA)
- Data cleaning
- Data visualisation
- Business problem solving
- Data storytelling

## Business Questions
1. How do sales and order volumes change over time?
2. Which product categories generate the most revenue?
3. Which Brazilian states generate the most orders and revenue?
4. Which customers make repeat purchases?
5. How does delivery performance relate to review scores?
6. Which product categories receive the highest and lowest review scores?
7. What payment methods are used most often?
8. Which sellers generate the most revenue?

## Dataset
Source: Brazilian E-Commerce Public Dataset by Olist on Kaggle.

The raw CSV files are intentionally excluded from this repository. Download them from the original Kaggle dataset and place them in the `data/` folder.
